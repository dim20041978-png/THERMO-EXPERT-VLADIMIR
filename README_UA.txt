THERMO EXPERT VLADIMIR — Android Studio project

ЩО ЦЕ:
Початковий Android-проєкт, який відкриває локальний інтерфейс програми у WebView. HTML-файл вбудований у застосунок, тому для запуску інтерфейсу не потрібен вебхостинг або інтернет.

ЯК ЗІБРАТИ APK:
1. На комп'ютері встановіть Android Studio (версію з підтримкою Android Gradle Plugin 8.7.3) та Android SDK Platform 35.
2. Розпакуйте ZIP.
3. В Android Studio оберіть File → Open і відкрийте папку THERMO_EXPERT_VLADIMIR_AndroidProject.
4. Дочекайтеся Gradle Sync. Якщо Android Studio запропонує встановити SDK 35 або компоненти збірки — погодьтеся.
5. Для тестового APK: Build → Build Bundle(s) / APK(s) → Build APK(s).
6. Після успішної збірки APK буде у app/build/outputs/apk/debug/app-debug.apk.
7. Перенесіть APK на телефон Android і відкрийте його. Дозвольте встановлення з цього джерела, якщо Android попросить.

ДЛЯ ПУБЛІКАЦІЇ / РОЗПОВСЮДЖЕННЯ:
Потрібно створити підписаний релізний APK через Build → Generate Signed Bundle / APK та зберегти ключ підпису в безпечному місці.

ВАЖЛИВІ ОБМЕЖЕННЯ ПОТОЧНОЇ ВЕРСІЇ:
- Це стартовий WebView-контейнер із вбудованим прототипом, а не перевірений виробничий застосунок.
- Перед реальною експлуатацією необхідно протестувати збереження даних, імпорт/експорт, камеру та PDF на конкретному телефоні.
- Дані зберігаються у локальному сховищі WebView цього застосунку. Видалення застосунку або очищення його даних може стерти записи; регулярно експортуйте резервну копію.
- Вибір фото підтримується через системний файловий вибір Android. Поведінку запуску камери треба перевірити на цільовому пристрої.
- Звичайна камера телефону не вимірює температуру. Для теплових вимірювань потрібен сумісний зовнішній тепловізор або імпорт зображень із нього.
- У цьому середовищі Android SDK/Gradle не встановлені, тому APK тут не скомпільовано й не підписано.


АВТОМАТИЧНА ЗБІРКА APK ЧЕРЕЗ GITHUB ACTIONS
1. Завантажте весь вміст цього проєкту в новий GitHub-репозиторій (гілка main або master).
2. Відкрийте вкладку Actions та запустіть Build Android APK (або дочекайтеся збірки після push).
3. Після успішного завершення відкрийте запуск workflow і завантажте Artifact THERMO-EXPERT-VLADIMIR-debug-apk.
4. Розпакуйте artifact та встановіть app-debug.apk на Android. Для тестової збірки може знадобитися дозволити встановлення з цього джерела.

ВАЖЛИВО: у поточному середовищі немає Android SDK/Gradle, тому APK тут не зібрано і запуск на реальному пристрої не перевірено. GitHub Actions виконає компіляцію; перевірка на фізичному телефоні все одно потребує встановлення та тестування. Це debug APK, не підписаний релізний пакет для Google Play.
